# Frontend
Code Convention

| Prefix (type) | 설명 |
|--------------|------|
| `feature:`   | 새로운 기능 개발 |
| `fix:`       | 버그 수정 |
| `refactor:`  | 리팩토링 (기능 변경 없음) |
| `style:`     | 코드 스타일 변경 (포맷팅, 세미콜론, 들여쓰기 등) |
| `ui:`        | UI 디자인 및 CSS 수정 |
| `docs:`      | 문서 변경 |
| `test:`      | 테스트 코드 추가 |
| `chore:`     | 설정, 빌드, 패키지 관리 등 기타 작업 |
